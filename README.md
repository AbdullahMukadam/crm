# StudioFlow

The all-in-one suite for freelance designers to win clients, manage projects, and get paid. No more scattered tools.

![StudioFlow landing page with the leads pipeline dashboard](public/readme-screenshot.png)

## Features

- **Deal Management (CRM)**
- **Proposal Builder**
- **Client Portal**
- **Invoicing & Finance**
